# COSC2821 / COSC2650 Milk Tea Product Repository

This is the controlled starter resource for the Cloud Developing milk-tea website assignment.

## Contents

- `images/` – supplied milk-tea product images
- `products.csv` – starter product metadata

## Student instructions

You must use the supplied product images as part of your milk-tea website.

You are responsible for designing and developing the website. The following are intentionally NOT provided:

- HTML/CSS/JavaScript website implementation
- DynamoDB schema
- Lambda source code
- API Gateway definition
- Step Functions definition
- SNS/SQS implementation
- Dockerfile
- AWS CLI/SDK scripts

You may decide:

- website name and branding
- layout and navigation
- product presentation
- search/filter functionality
- customer interaction/order functionality
- DynamoDB design
- API design
- Lambda decomposition
- workflow design
- additional features

## Product data

The `products.csv` file is starter data only. You should use it to initialise your application and may adapt the presentation and application design according to the assignment requirements.

## Important

The image filenames are provided as controlled course resources. Do not assume that the images may be reused outside the course assignment.
